# distill-lessons

方法见 `~/.agents/framework/playbooks/knowledge-system.md` §2、§4、§6。

## 1. 找候选
- 本会话：我纠正你的地方、根因翻转的地方、你花了很久才找到的东西、我重复解释的东西。
- 批量：按**集合差**找未吸收的会话（不是按时间窗），从原始 transcript 抽内容，不凭标题猜。

## 2. 每个候选抽 5 个字段
`症状 / 转折点（哪个证据改变了方向）/ 根因 / 模式签名（下次怎么一眼认出）/ 该落到哪（core、playbook、领域 SOP、skill、memory）`

## 3. 分类
- 命中已有规则 → 计数 +1，加 case 引用
- 细化已有规则
- 新规则 → 需要 ≥2 个独立证据，否则放「观察中」
- 路由修改（skill 关键词 / 路由表）
- 新 skill 候选
- 流程缺口（「没复现 / 没看附件 / 没扫群」）→ 补进对应 skill 的步骤

## 4. 写法检查
- 泛化：不写 case 编号和个案答案；因果类错误写成去标识的演练，不写答案。
- 一条 = 判据 + Why（日期 + 事件）+ How to apply。
- 先查有没有已存在的同主题文件，更新而不是新建；发现矛盾 / 过期的就地修正。
- 不写密钥，只写位置。

## 5. 输出 DIFF，等确认
```
[1] 新规则 → <文件>  （证据：会话 A、会话 B）
+ …
[2] 观察中 → <文件>
+ …
[3] 修正过期 memory → <文件>
- 旧
+ 新
```
回复语法：`all` / `1,3` / `cases only` / `skip`。我没回复就不动文件。写完如果有云端镜像，同步并验证。
