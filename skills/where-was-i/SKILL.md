# where-was-i：断点续接看板

目标：30 秒内知道「现在有几条线、每条到哪了、哪些在等我」。

确定性的部分（扫会话、过滤、分类、分组）由脚本做：`~/.agents/framework/kit/board.py`。你只负责两件事：给没有状态卡的会话补一句推断，以及把结果按下面的格式交给我。

## 步骤

1. **跑看板脚本**（时间窗按我说的话定：默认 48h；「今天」→ 24h；「这周」→ 7d）：
   - 你所在的 runtime 能渲染 app 内可点击链接（Claude 桌面端）→ Markdown：
     `python3 ~/.agents/framework/kit/board.py --since 48h`
   - 终端 / Codex / 其他 → 纯文本，每个会话附「接着做」的命令：
     `python3 ~/.agents/framework/kit/board.py --since 48h --text`
   - 需要逐条细看时加 `--json`（含每个会话最后一段回复 `last_text`、首句 `extra.first_prompt`、transcript 路径）。
   - **排除你自己**：知道自己的会话 id 时加 `--exclude <id>`；不知道就在结果里去掉「正在运行、最近活动 0 分钟前、首句就是这次请求」的那一条。
2. **补推断**：`--json` 里 `card` 为 null 的会话（Markdown / 文本里标「（无状态卡，待推断）」），用 `last_text` / `summary` / `first_prompt`
   概括出 📍目标 / ⏳当前 / 👉等你 三项（一句话一项），行尾标「(推断)」。`last_text` 只是结尾片段，不够判断就读 transcript 的最后几轮。
   - 推断出来是在**等我做决定 / 等我回答**（「要我推 PR 吗」「要不要先补开关」）→ 升到 👉 组，标「(推断)」，总览里的 K 也要加上。
   - 看不出在等什么 → 写「👉 不确定」；推断里提到的截止时间可能已过，写「可能已过时」。
   - 不要把推断写成事实。
   - 看到两个会话明显是同一件事 / 一个已经取代另一个，可以在下面加一行「注意：…」。
3. **原样保留脚本给的链接和命令**：Markdown 里 `[标题](#local_…)` 已经做了方括号 / 括号转义，不要改写；纯文本里的 `接着做：…` 命令照抄。
4. **交给我**（格式见下）。
5. **收尾问一句**：「可归档」那组要不要从看板上隐藏？要不要把某两条线开分屏 / 并排？
   - 看板隐藏（任何 runtime）：`python3 ~/.agents/framework/kit/board.py --hide <id> ...`（会话有新活动时会自动重新出现）。
   - runtime 自己的归档（例如 Claude 桌面端的会话归档）：**必须等我明确确认**再做。
6. 标题里没有 `[工作线]` 的会话，顺手建议一个标题，但不擅自改。

## 输出格式

```
N 条线 · M 个会话 · K 个在等你

### 👉 等你（K）
- <链接或标题> — 等你：<要做的决定>（⏳ <当前状态>）

### 🔄 在跑 / 可继续
**[工作线]**
- 🔄 <链接或标题> — 📍目标 · ⏳当前 · <多久前>       （推断的行：📍目标 · ⏳当前 · 👉等你 (推断) · <多久前>）

### ✅ 已完成 / 可归档
- <链接或标题> — 原因（状态卡写可以归档 / >3 天无活动）     （纯文本模式下保留脚本给的「接着做」命令）
```

- 等你的排最前；每个会话一行，不展开细节；🔄 = 正在运行。
- 中文；结尾附状态卡（这个 skill 自己也是一轮交互）。

## 个人配置（可选）：`~/.agents/board.json`

```json
{
  "workline_by_path": {"work/sales": "sales", "work/debug": "debug"},
  "skip_cwd": [".img-cache"],
  "automation_prefixes": ["你是值班自动首响", "你是工单分诊"]
}
```
- `workline_by_path`：标题和状态卡里都没有 `[工作线]` 时，按 cwd 路径片段推断工作线。
- `skip_cwd`：这些目录里起的会话不上看板（脚本、批处理）。
- `automation_prefixes`：首句以这些前缀开头的会话算自动化，不上看板。

## 看板为什么能跨 harness

它只依赖一个约定：**每轮末尾的状态卡**（core §1）。不能设会话标题的 runtime，把 `[工作线]` 写在 📍 行开头即可。
数据源适配器在 `kit/board.py` 的 `SOURCES` 里（目前 claude、codex）；接入新的 harness = 加一个读它会话文件的函数。
