# triage-ask

完整模型见 `~/.agents/framework/playbooks/autonomy-and-triage.md`（我的 4 档 × 3 类闸 × 默认叶子）。

## 步骤
1. **stage0 丢弃**：bot / 我自己发的、广播、别的系统负责的、没直接找我、没有新输入 → skip，不调 LLM 的判断能做完就别多想。
2. **拆 ask**：只从对方的消息里拆（我的消息只是上下文）；不同交付物分开；预告的任务也算。客套 / FYI / 已完成通知 → 无 ask。
3. **按交付物分类**（别被句式误导：问进度 ≠ 改代码）。
4. **过闸**：
   - 在此前停：对外发言 / 写操作 / 业务口径决策 / 需要我本人
   - 只改状态（档位不变）：已在处理 → 同步进度；已解决
   - 丢弃：重复 / 不是我的 / 一句话能答 / 纯通知（注意每条的反例）
5. **定档**：叶子默认档 → 第一条命中的规则覆盖。

## 输出
```
交付物 = ___ ｜ 档 = full/partial/no/skip ｜ 闸 = ___ ｜ stop_at = ___ ｜ needs = ___
步骤：1. … 2. … （停在 stop_at）
草稿回复（如需对外）：…（只起草，不发）
```

## 提醒
- `full` 也有 stop_at；不跨过不可逆的那一步。
- 涉及以我身份对外说话 → 按 playbook §5 的串联闸，任一不满足就只起草 / 私信我。
- 不要自创分支或档位；规则冲突时说明按哪条判的。
