# handoff-prompt

见 `~/.agents/framework/playbooks/multi-agent.md` §2。输出一个可直接粘贴的代码块，中文，按下面的结构，不省略。

```
# 任务：<一句话目标，交付物是什么、交到哪里>

## 背景
<为什么做这件事；相关链接（文档 / PR / 群 / 会话），全部可点击>

## 已证实的事实（带证据）
- <事实> —— <查询 / file:line / 消息 id>

## 已否决的假设（不要再走）
- <假设> —— <否决它的证据>

## 当前状态
<四态之一 + 做到哪一步；分支 / worktree / 关键文件路径>

## 下一步
1. …
2. …

## 约束
- 自主度：<哪些直接做 / 哪些停下等确认>，stop_at = <…>
- 不许碰：<…>
- 凭据 / 登录在哪：<只写位置>

## 验收标准
- <可运行的检查，针对原始症状>

## 输出要求
- 中文；交付物写成 <文档 / PR / 文件>；聊天给「问题 / 原因 / 修复」三句 + 链接；每轮末尾附状态卡。
```
生成前先把会话里的事实和证据核一遍：只放 ✓ 的进「已证实」，⚠ 的放「待验证」小节。
